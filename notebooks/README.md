# Clinical Paper Notebooks

This folder contains only the notebook and R Markdown table workflow for the clinical paper public snapshot.

- `clinical_paper/Clinical_main_work.ipynb`: downstream analysis notebook for diagnostics, figures, paper-facing summaries, and interpretation.
- `clinical_paper/PrepareData_demtable_paper1.Rmd`: baseline and demographic table workflow.

The table workflow depends on helper scripts exported at the repository root under `table_helpers/`.
