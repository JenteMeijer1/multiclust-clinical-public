# Clinical Paper Notebooks

This folder contains the paper-facing clinical multiclust notebook files.

## Files

- `clinical_paper/Clinical_main_work.ipynb`: downstream analysis notebook. Use this after pipeline outputs have been generated.
- `clinical_paper/PrepareData_demtable_paper1.Rmd`: R Markdown workflow for baseline and demographic tables.

## Notes

- Notebook outputs are stripped in this public snapshot to keep the repository smaller and avoid publishing private outputs.
- The R Markdown file depends on `table_helpers/` in the repository root.
- Data paths inside the notebook and R Markdown file are placeholders. Replace them with local paths before running.
